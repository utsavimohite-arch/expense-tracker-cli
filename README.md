# Expense Tracker Application

## Project Information

- Project Name: Expense Tracker Application
- Organization: CodeOrbit Tech
- Programming Language: Python
- Application Type: Command Line Interface (CLI)
- Data Storage: CSV File
- Document Type: Software Requirements Specification (SRS)
- Version: 1.0

## Project Description

The Expense Tracker Application is a Python-based
command-line application designed to help users
record, manage, and monitor their daily expenses.

The application stores expense information in a CSV
file for future access.

## Planned Features

1. Add new expenses.
2. View all expenses.
3. Search expenses by category.
4. Calculate total expenses.
5. View category-wise expense summaries.
6. Delete expenses.
