
# Expense Tracker Application - Changelog

## Version 1.0.0

### Initial Setup
- Created the Expense Tracker CLI application.
- Set up the Python project structure.
- Created the GitHub repository.

### Expense Management
- Added functionality to record expenses.
- Generated unique IDs for expenses.
- Added automatic date recording.

### CSV Storage
- Integrated CSV file storage.
- Implemented saving and loading of expenses.
- Added persistent storage between application sessions.

### Expense Viewing and Searching
- Added the option to view all expenses.
- Added category-based expense searching.

### Expense Calculations
- Added total expense calculation.
- Added category-wise expense summaries.

### Expense Deletion
- Added expense deletion using unique IDs.
- Added confirmation before deleting records.

### Validation and Error Handling
- Added input validation.
- Handled invalid amounts and expense IDs.
- Added CSV reading and writing error handling.
- Added protection against invalid CSV records.
